# Notiq

### How to add your sticky note

1. Open `data.json` in this repo.
2. Copy the template below and paste it **inside the array**, before the closing `]`.
3. Replace the text fields with your message.

```json
{
  "id": "YOURNAME-1",
  "x": 1200,
  "y": 800,
  "text": "Your positive message here",
  "name": "Your name",
  "color": "#ffbeefff",
  "updatedAt": 1690000000000
}
